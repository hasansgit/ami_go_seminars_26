## 1. `DivMod`

```go
func DivMod(dividend, divisor int) (quotient, remainder int, err error)
```

Частное и остаток. При `divisor != 0` результат должен совпадать с обычными
`dividend / divisor` и `dividend % divisor` — в том числе на отрицательных
числах, где Go округляет частное к нулю, а остаток берёт знак делимого.

При `divisor == 0` — нулевые частное и остаток плюс ошибка `ErrDivisionByZero`.
**Паниковать при ожидаемой ошибке нельзя**: паника — это про сломанный
инвариант, а деление на ноль вызывающий код умеет обработать.

Именованные результаты в сигнатуре есть, а голый `return` использовать не
стоит: пока вы привыкаете к множественному возврату, полезно видеть глазами,
что именно возвращается.

## 2. `Grant`, `Revoke`, `Has`

```go
func Grant(current, added Permission) Permission
func Revoke(current, removed Permission) Permission
func Has(current, required Permission) bool
```

Права — независимые биты одного значения `Permission`, а не три поля `bool`.
Константы заданы через `1 << iota`, смотреть в `types.go`.

Три оператора, которых хватает на всю задачу:

```go
current | added    // включить биты
current & required // оставить общие биты
current &^ removed // сбросить биты
```

`Has` возвращает `true`, только если присутствуют **все** биты из `required`.
Частая ошибка — написать `current & required != 0`: это ответ на другой вопрос,
«есть хотя бы одно из прав». Отдельно проверьте `Has(current, 0)` и объясните
себе полученный ответ до того, как посмотрите в тест.

Функции не меняют аргументы: `Permission` передаётся по значению.

## 3. `New`

```go
func New(start, step int) func() int
```

Фабрика счётчиков. Возвращённая функция **сначала увеличивает** значение на
`step`, потом возвращает его:

```go
next := New(10, 3)
next()  // 13
next()  // 16
```

Ключевая проверка — `TestCountersAreIndependent`: два счётчика, полученные
разными вызовами `New`, обязаны быть независимы. Если вы использовали
переменную уровня пакета вместо локальной, тест это поймает. Глобальные
переменные в этой задаче запрещены.

## 4. `Prepend`, `Length`, `Find`, `Reverse`

```go
func Prepend(head *Node, value int) *Node
func Length(head *Node) int
func Find(head *Node, value int) *Node
func Reverse(head *Node) *Node
```

Односвязный список. Отдельного типа `List` нет: пустой список — это `nil`,
то есть нулевое значение указателя. Все четыре функции обязаны корректно
работать с `nil` на входе.

Главная мысль задачи: **указатель тоже передаётся по значению.** Присвоив
внутри функции `head = ...`, вы поменяете только локальную копию — поэтому
операции, меняющие голову списка, возвращают новый указатель.

`Find` возвращает указатель на существующий узел, а не копию — тест сравнивает
именно адреса. `Reverse` разворачивает связи между существующими узлами,
создавать новые узлы в нём не нужно.

Делайте в порядке `Prepend` → `Length` → `Find` → `Reverse`. Перед `Reverse`
нарисуйте на бумаге три указателя `previous`, `current`, `next` и убедитесь,
что понимаете, почему `next` нужно сохранить **до** того, как поменяли связь:
иначе остаток списка станет недостижим.

## 5. `Map`

```go
func Map(root *Node, transform Transform) (*Node, error)
```

Глубокая копия бинарного дерева с преобразованием значения в каждом узле.
Самая содержательная задача семинара — читайте контракт в doc-комментарии
целиком, там каждый пункт проверяется тестом.

На что обратить внимание:

- **Порядок обхода `root → left → right` — часть контракта.** `Transform`
  может оказаться замыканием с состоянием, и тогда перестановка вызовов
  меняет наблюдаемое поведение. Тест сверяет порядок вызовов.
- **Узлы результата должны быть новыми.** Переиспользовать узлы исходного
  дерева нельзя, менять их — тем более. Тест рекурсивно проверяет, что общих
  узлов нет.
- **После первой ошибки обход прекращается**, наружу возвращается `nil`, а не
  частично построенное дерево.
- **Ошибка оборачивается через `%w`**, и контекст обязан содержать значение
  сбойного узла. Оборачивание через `%v` тест не пройдёт: `errors.Is`
  перестанет находить исходную ошибку.
- `Map(nil, transform)` — это `(nil, nil)`, при этом `transform` не вызывается.
  `Map(root, nil)` — это `ErrNilTransform`, даже если дерево пустое.
